A program that writes one funny line about office life to
`/output/entry.txt`, for the make.fun competition
[Make the AI Judge Laugh](https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225).

Run it with Python 3:

```
python3 main.py
```

It writes the joke below to `/output/entry.txt` (or to the path given in
`$OUTPUT_PATH`). No network, no clock, no randomness. The joke is 120
characters, one line, inside the 1 to 200 gate. It is a different joke
from the one already submitted today to the other "Make the AI Judge
Laugh" bounty (entry 160, the standing desks line).

## The joke

```
Our boss said the meeting could have been an email, then scheduled a meeting to discuss why it could have been an email.
```
